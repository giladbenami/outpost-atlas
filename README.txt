OUTPOST / AN ATLAS - Prototype 01

1. Open index.html in a modern desktop browser with an internet connection.
2. Click the dots on the map or the events on the bottom timeline.
3. Click related objects in the side panel to move between sites.
4. Switch between street map and satellite imagery (requires tile provider access).
5. To add content, edit the OBJECTS array in index.html. Each entry has an ID, year, coordinates [longitude,latitude], tags, description and related IDs.

IMPORTANT: The three objects are placeholders and example positions/dates are approximate. Replace with verified research data and images. The timeline is 1880-2026 and can be extended in the JavaScript variables minYear and maxYear.

Map rendering relies on internet/CDN and third-party map tile availability. Deployment on a web host is preferable to opening file:// for production use. Check map imagery provider terms before public launch.
